### 额外测量

| 指标 | 实测 | 说明 |
|---|---|---|
| OCR worker 峰值内存 | 369.5 MB | 1280×720 图片，PP-OCRv5 中文模型 |
| OCR 单张耗时 | 2.1–2.7 s | 含模型初始化（每次新进程） |
| worker 目录体积 | 499.4 MB | PaddleInference + MKL + OpenCV + 12 组模型 |

### 未实测项与原因

- **热键被占用**：需要另一个程序占住 `Ctrl+Alt+S` 并保持消息循环，脚本化成本高于收益。代码路径已覆盖（`Register()` 返回 false → 托盘提示 + 日志）。
- **插件抛异常**：需要临时改插件源码。`PaletteViewModel` / `WorkspaceViewModel` 都在 `ExecuteAsync` 外套了 try/catch，M1 先接受。

### 结论

9 条出口条件全部达标或已实现；2 条属于「已实现但未构造故障场景」。

**M1 可以收尾**，下一阶段优先级：

1. OCR 换轻量模型（RapidOCR）——当前 500 MB 体积和 369 MB 峰值内存是最大负担
2. 截图动作栏（OCR / 复制图片 / 保存）
3. 滚动截图（`ImageSetInput` + 宿主捕获）
