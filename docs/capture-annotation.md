# 截图标注（设计稿）

> 结合两个参考：
> · **snow-shot**（Qt/C++）：工具条分组、布局紧凑、锚定放置（已用于 `docs/capture.md`）
> · **LumaShot**（Win32/C++）：**按工具切换的属性行**（`tool_properties.h` + `ui/toolbar.cpp`）、马赛克/箭头/画笔的完整参数

目标：截图工具条从「只能识别/复制」升级为「能画、能遮、能标序号」，并保持深灰 + 琥珀的视觉。

## 一、工具

| 工具 | 行为 | 参考 |
|---|---|---|
| 选择/移动 | 默认态：拖选区、拖动标注、拉控制点 | LumaShot `Tool::Select` |
| 矩形 | 拖拽出框；可调圆角与填充透明度 | 两边都有 |
| 椭圆 | 拖拽出圆/椭圆 | LumaShot |
| 箭头 | 起点→终点；箭头头部大小/样式可调 | LumaShot `model/arrow.cpp` |
| 画笔 | 自由、直线、连续直线三种轨迹；连续线条做平滑 | LumaShot `Pen` |
| 文字 | 点一下出输入框，提交后成为图元；字号/背景可选 | snow-shot |
| 马赛克 | 像素/模糊两种模式；涂抹/框选两种方式；密度可调 | LumaShot `Mosaic` |
| 序号 | 点一下递增编号，圆形/方形，可改颜色 | LumaShot `Number` |
| 高亮 | 半透明粗笔画，用于划重点 | LumaShot `Highlighter` |

第一版做：矩形、椭圆、箭头、画笔、文字、马赛克（6 个），序号与高亮放第二版。

## 二、工具条布局（合并两边）

> 2026-11-21 更新（第三轮，对齐 LumaShot 截图）：主工具条收成**一行**，
> 属性单独做一张浮条，按当前工具显示；确认/取消固定在最右。

```
┌ 工具条（一行）─────────────────────────────────────────────────────┐
│ ⠿ ▭ ◯ ↗ ✎ ▤ ▦ T ① | ↖ ↶ ↷ | 识别 译 存 钉 滚 圆角 | ✕ ✓          │
└────────────────────────────────────────────────────────────────────┘
┌ 属性栏（仅选中工具时，宽度随内容）─────────────────────────────────┐
│ 颜色 ●●●●●🎨 | 线宽 [3 px▾] | 线型 [实线▾] | 填充 [无▾] | 透明度 ─● 100% | 圆角 ─● 0 px | ★ │
└────────────────────────────────────────────────────────────────────┘
```

- **✓ 是唯一的主按钮**（琥珀实心）：完成并复制，等价于原来的「复制图片」。`✕` 取消截图。
- **指针（1）、撤销、重做** 放在工具组之后；`Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`）对应撤销/重做。
- **属性栏按工具裁剪**（LumaShot 的属性卡思路）：
  - 矩形：颜色、线宽、线型、填充、透明度、圆角；
  - 椭圆：颜色、线宽、填充、透明度；
  - 箭头 / 画笔 / 高亮：颜色、线宽、线型、透明度；
  - 文字：颜色、字号、加粗；
  - 序号：颜色、大小；
  - 马赛克：像素/模糊、笔刷大小。
- **自定义颜色**：色块组最后的彩虹按钮打开 HSV 拾色器（色相条 + 饱和度/明度面板 + Hex + 最近使用色）。
- 工具条和属性栏都**居中锚定**在选区下方（放不下翻到上方、钳制在窗口内）；
  属性行显隐改变宽度时，等布局完成再按实际 `Bounds` 校正一次居中。

**工具条可拖动**：主工具条最左侧是拖动把手（`SizeAll` 光标）。拖过之后工具条不再跟随选区，
位置钳制在窗口内；这是每个截图窗口独立的状态，下次呼出重新按选区定位。

**窄窗口折叠**：窗口宽度 < 720 DIP 时，`保存 / 固定 / 滚动 / 圆角` 收进「更多」图标菜单；
`✓` 在任何宽度都保留。阈值在 `CaptureWindow.ShouldCompact`，布局切换在 `SetToolbarCompaction`。

关键点：

1. **属性行按工具切换**（取自 LumaShot），不把十几种参数全铺出来。
2. **主条 / 属性条分离**（取自 LumaShot）：动作区不会因为切工具而移动。
3. **宽度不够时折叠**：低频动作收进「更多」（snow-shot 的 layout compaction）。
4. 放置规则沿用 `CaptureWindow.ComputeToolbarPosition`（居中对齐、放不下翻上方、钳制）。

### 标注样式能力（2026-11-21）

| 属性 | 适用范围 | 实现 |
|---|---|---|
| 颜色 | 除马赛克外的所有工具 | 5 个预设 + 自定义 HSV 拾色器 |
| 线宽 | 矩形/椭圆/箭头/画笔/高亮 | 2 / 3 / 4 / 8 / 12 px |
| 线型 | 矩形/箭头/画笔/高亮 | 实线 / 虚线 / 点线（Skia `DashPathEffect`） |
| 填充 | 矩形/椭圆 | 无 / 淡色（28% 透明度）/ 实心 |
| 透明度 | 矩形/椭圆/箭头/画笔/高亮 | 20–100% |
| 圆角 | 矩形 | 0–40 px（导出时 `DrawRoundRect`） |
| 字号 / 加粗 | 文字 | 14–32 px；本地输入框同步 |
| 大小 | 序号 | 16 / 24 / 32 / 48 px |
| 笔刷 | 马赛克 | 8 / 12 / 20 px 像素格 |

导出（Skia）和预览（Avalonia 图元）用同一组字段，单测覆盖填充、圆角、透明度的像素结果。

## 三、数据模型

```csharp
// 纯数据，便于撤销与重放；坐标是 DIP，导出时乘 _scaling
abstract record Annotation;
record RectNote(Rect Rect, uint Color, double Width, double CornerRadius, double FillOpacity) : Annotation;
record EllipseNote(Rect Rect, uint Color, double Width, double FillOpacity) : Annotation;
record ArrowNote(Point From, Point To, uint Color, double Width, double HeadSize) : Annotation;
record PenNote(IReadOnlyList<Point> Points, uint Color, double Width, double Opacity, PenMode Mode) : Annotation;
record TextNote(Point Origin, string Text, uint Color, double FontSize, TextBackground Background) : Annotation;
record MosaicNote(Rect Rect, MosaicMode Mode, MosaicMethod Method, double Cell, int Strength) : Annotation;
```

- 撤销 = 弹出最后一条并重画（不做命令模式，图元都是不可变记录，够用）。
- 重做保留一个 `Stack<Annotation>`，画新图元时清空。
- 所有图元存 `List<Annotation>`，`OnRender` 按顺序画。

## 四、导出合成

**不要**用 Avalonia 截图渲染（高 DPI 会发虚）。用 SkiaSharp 直接画到物理像素：

```
1. CaptureSelectionAsync 拿到选区 PNG（原尺寸）
2. 新建 SKCanvas(png)，按 _scaling 缩放坐标系
3. 依次画图元（马赛克先做降采样/模糊，再画到 canvas）
4. 复制 / 保存 / 固定 / 识别 都用这张合成后的 PNG
```

项目已依赖 SkiaSharp 3.119.4，OCR 插件也在用；不需要新包。

## 五、交互细节（易踩的坑）

| 坑 | 处理 |
|---|---|
| 标注与拖选区打架 | `DragMode` 增加 `NoteEdit`；有画图工具时先画，指针工具下先看是否点中标注 |
| 文字输入法 | 用真实 `TextBox` 浮在选区上，提交后转 `TextNote`；不要自绘文本 |
| 高 DPI | 图元存 DIP，导出时乘 `_scaling`；线宽用像素对齐（`.5` 偏移） |
| 马赛克格子 | 按**物理像素**算单元格大小，否则 150% 缩放下格子不一致 |
| 撤销后悬停态 | 重画时清掉命中缓存，避免抓到已删除的图元 |
| 工具条太宽 | 见第二节的折叠规则；7 个动作 + 6 个工具一定超宽 |

### 吸附到检测到的窗口（2026-11-21）

选区创建时记住它覆盖的那个窗口（`_candidateAtPress`），拖动/拉伸时把该窗口的
左右边、中线也作为参考线（`SnapGuides.Combine`）。这样「贴着窗口挪」「对齐窗口中线」不用靠手抖。

### 选区视觉（2026-11-21）

参考 snow-shot / LumaShot 的选区观感，这次把「选区」本身也补齐：

| 项 | 做法 |
|---|---|
| 只压暗外面 | `DimLayer` 从整屏矩形改成 `Path` + `CombinedGeometry(Exclude)`：全屏减去选区，选区内保持原图亮度 |
| 悬停预览 | 还没有选区时，遮罩的洞跟着悬停候选窗口走，整窗高亮（与「智能选区」一致的观感） |
| 十字辅助线 | 未框选时光标处两条 1px 琥珀线贯穿屏幕，帮助对齐；框选完成后消失 |
| 放大镜 | 拖动 / 移动 / 拉伸时在光标旁显示 4× 圆形放大镜（132 DIP），带十字和中心点；依次尝试四个角，避开工具条与屏幕边缘 |
| 控制点 | 小方块（7×7、圆角 1.5），白底 + 深色描边，亮背景也看得清 |
| 边界描边 | 选区外再套 1px 深色描边（`SelectionHalo`），亮内容上也能分出边界 |
| 尺寸角标 | `宽 × 高` 输入框（可直接改尺寸）+ 单位切换 + 宽高比锁 |

放大镜直接用冻结帧做 `ScaleTransform`，不复制像素、不额外占内存；没有冻结帧（测试 / 无桌面）时自动隐藏。
位置计算抽成 `CaptureWindow.PlaceMagnifier` 纯函数，单测覆盖「不压工具条」。

### 尺寸单位与圆角（2026-11-21）

| 项 | 做法 |
|---|---|
| 尺寸单位 | 角标右侧的 `px` 按钮在 **物理像素 / DIP** 之间切换，选择写进设置（`CaptureSizeUnit`） |
| 圆角 | 工具栏「圆角」开关（半径 10 DIP），导出时用 Skia 把四角切掉（透明背景），设置里持久化 |

### 尺寸可编辑与锁比例（2026-11-21，第四轮）

参考 snow-shot 工具条里的尺寸输入框：选区角标从「只读读数」升级成**可编辑**。

```
┌───────────────────────────────────┐
│  620  ×  300  px   🔓            │
└───────────────────────────────────┘
```

- **两个输入框**：宽 / 高，单位跟当前显示单位一致（`px` 或 `DIP`）。
  `Enter` 提交并把焦点交还窗口（数字键继续用来切工具），`Esc` 放弃输入，
  失焦时提交；空 / 非数字 / ≤0 都视为无效，恢复成当前值。
- **单位按钮** `px` ↔ `DIP`：原来的「点角标切单位」挪到这里，输入框不会被误触。
- **锁比例**：开启后只按最后编辑的那个维度推算另一边（`axis` 参数区分宽/高）。
- **钳制**：最小 8 DIP，且不越过窗口右下边界（左上角不动）。
- 提交后走 `UpdateSelectionVisuals` → 控制点 / 遮罩 / 工具条一起跟上，
  标注预览层也重画（图元是选区相对坐标）。
- 角标宽度随内容变化，放置前 `Measure` 一次，不再用写死的 150 DIP。

实现位置：`CaptureWindow.CommitSizeEdit` / `UpdateSizeBadge` / `TryParseSize`。

### 右键逐级后退（2026-11-21，第四轮）

和参考工具的肌肉记忆一致，一次右键退一级：

1. 拾色器开着 → 收起拾色器；
2. 选中了标注工具 → 回到指针工具；
3. 有识别结果 → 关掉识别框；
4. 有选区 → 清空选区（`ResetSelection`，序号计数器归 1）；
5. 什么都没有 → 取消截图（`Action = None` + 关窗）。

### 标注选中 / 拖动编辑（2026-11-21，第四轮）

| 操作 | 行为 |
|---|---|
| 指针工具下点中标注 | 选中并画琥珀虚线外框（外扩 3 DIP） |
| 拖动选中的标注 | 整体平移，叠放顺序不变（`AnnotationDocument.Replace`） |
| 点标注外的空白 | 取消选中，继续原来的「移动/拉伸选区」 |
| `Delete` / `Backspace` | 删除选中那条（`AnnotationDocument.RemoveAt`，清重做栈） |
| 切到画图工具 / 撤销 / 重做 | 自动取消选中 |
| 撤销/删除导致索引越界 | `RebuildNotePreview` 里兜底重置为 -1 |

命中测试（`HitTestNote`）：空心形状只认边框 ±6 DIP（中间留空，方便穿过去操作别的），
实心形状整块可点；箭头/画笔按线段到点距离，序号按圆半径，文字按估算字宽
（中日韩 1 字号、西文 0.6 字号）。

**已知限制**：删除不可撤销（`RemoveAt` 清掉重做栈，撤销仍是「弹出最后一条」的语义）；
文字的命中框是估算值，单行之外的换行宽度会偏小。

## 七、验收

- 画完 → 复制 / 保存 / 固定 / 识别，四个出口拿到的都是**带标注**的图
- 150% 与 100% 缩放下，箭头粗细与马赛克格子视觉一致
- 撤销 20 步不卡（每次重画是 O(n)，n 很小）
- 选区重设后标注清空（避免旧图元落在新选区外）
