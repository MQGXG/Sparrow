# 截图选区与工具条

> 参考了 snow-shot 的 `anchoredToolbarPlacement` 与工具条结构，按 Sparrow 的深灰 + 琥珀配色重画。

## 一、动作

| 按钮 | 快捷键 | 行为 |
|---|---|---|
| 识别文字 | Enter / R | OCR 选图，结果以行框叠在选区上，可点一行复制一行 |
| **翻译 ▾** | — | 点开选目标语言（来自 OCR 工具的 12 种），识别后附译文 |
| 复制图片 | C | 选区 PNG 进剪贴板 |
| 保存 | S | 另存 PNG |
| 固定 | P | 贴到屏幕上（滚轮缩放） |
| 滚动 | G | 进入滚动截图 |
| 取消 | Esc | 关闭 |

「翻译」的语言列表**不写死在截图窗口里**：`App.TranslateTargets()` 直接读 OCR 工具
`translate` 参数的 `Choices`，跳过「不翻译」。插件加语言，截图工具条自动跟着变。

## 二、翻译流程

```
拖出选区
  → 点「翻译 ▾」选 English
  → CaptureSelectionAsync 按选区取 PNG（有冻结帧就裁冻结帧，不再抓屏）
  → OcrRunner(png, CaptureOcrOptions("English"), ct)
  → 宿主把 parameters["translate"] = "English" 交给 OCR 工具
  → 在线 AI 优先；没配 AI 时用已下载的本地模型
  → 行框 + 译文叠层（按行/格烧进图）
```

识别文字留在图上：行框可点选、可复制；译文直接画回截图，可用独立译文行切原文 / 左右对比。
表格选区按格识别、按格翻译（见 `ocr-text-layer.md` §2.2）。

## 三、工具条放置

```
首选：水平居中到选区，放在选区下方，间距 8
放不下：翻到选区上方
上方与尺寸浮条重叠：叠到浮条上方
再不行：选区左右两侧
最后：横向 / 纵向钳制在窗口内，边距 8
```

- 工具条和属性栏作为一个整体测量（`ActionBar.DesiredSize`）；属性栏按可用宽度**整组换行**（`SpacingWrapPanel`），不再固定 921 宽溢出。
- 尺寸浮条和工具条共用同一套避让：`ComputeToolbarPosition(selection, size, bounds, avoid)`。
- 动作条压缩按**实测主条宽度**决定，不再用窗口宽度阈值；OCR / 翻译按钮出现后会重新测量。
- 工具条 / 属性栏 / 尺寸浮条都按**选区所在显示器**的 DIP 边界钳制；手动拖动工具条也不会跨到别的屏。
- 纯函数在 `CaptureWindow.ComputeToolbarPosition`，用例覆盖「翻上方」「贴边钳制」「浮条避让」「跨屏边界」。
- 移动 / 拉伸选区时，标注从拖动开始时的快照反向平移，保持屏幕位置，不再清空；`Ctrl+Z` / `Ctrl+Shift+Z` 会把选区和标注一起回退/重做。

### 选区操作补充

- 拖建选区时按住 `Shift`：正方形；如果已锁比例，则沿用锁定比例。
- 方向键微调选区 1px，`Shift + 方向键` 10px，每次按键可撤销。
- `Esc` / 右键在“正在拖选区、拖标注、画一半”时先取消这次操作，不会直接关窗；再按一次才退出。
- 导出圆角会实时反映在选区边框和遮罩挖洞上，不再是“导出后才知道”。
- 窄窗口压缩分两级：先收低频动作到「更多」；仍放不下时再收起 OCR 状态、复制全部、识别框与格式/标点/引擎，翻译保留。
- 撤销覆盖新增、删除、擦除、拖动和文字修改；删除/擦除会插回原索引，拖动会回到原位置。
- 工具组悬停 120ms 才展开，移开 150ms 收起，鼠标扫过不会误触；点触发按钮仍然立即激活入口。
- 手动拖过的工具条位置按当前显示器的 0–1 比例保存，下次截图恢复；选区移动后仍恢复为跟随。
- 工具/属性按钮可 Tab 聚焦；折叠组聚焦后按 `↓` 展开并把焦点放到入口，`Esc` 收起并回到触发按钮。
- 选中标注（指针工具）后显示 8 个琥珀描边控制点，可拖动缩放；矩形/括号/气泡/文字另有旋转手柄（Shift 吸附 15°）。文字缩放会跟着改字号。

识别结果不再弹浮卡：文字留在图上（行框可点选复制），长文本去工作区看。
复制全文时可在工具条上选「格式 ▾」（不处理 / 保留换行 / 去掉换行 / 智能排版）和「标点 ▾」（不处理 / 半角 / 全角）。

### 3.1 窗口 / 控件自动识别（对齐 snow-shot）

悬停时先框窗口，再自动收紧到光标下的控件；实现分两段：

1. **首屏 170ms 预算**：探测到点就返回，绝不卡住鼠标；遍历途中约 40ms 发布一次越来越小的粗框（连 Pane/Group 也发布，深树里框会逐层收紧）。
2. **光标停住后细化 1.5s**：用同一棵缓存树把路径走到底，途中继续发布；**光标一移动就取消细化**，下一个位置立刻重新探测，不会排队等 1.5s。

浏览器（Chromium/Edge）第一次查询才懒启用无障碍树；更关键的是，**遮罩把浏览器窗口完全盖住后 Chromium 会关闭网页无障碍树**，此时 UIA 只剩窗口 / 文档 / 窗格，重试也拿不到行、链接、按钮。所以截图前会先对**光标下所有浏览器窗口**（最多 2 个，不只最上层）预建 UIA 树：`SetForegroundWindow`（仅最上层那个）→ IAccessible 激活 → `PrewarmAsync`（1.5s）建扁平快照，成功后再显示遮罩，遮罩期间直接用快照命中行级元素。只看最上层会漏掉浏览器——从 VS 按 F5 后再触发时，最上层往往是 VS/任务栏。没有预建树时，浏览器窗口首次探测前也会先做一次 IAccessible 激活并等待 120ms。

窗口候选的规则和 snow-shot 一致：只排除 **点击穿透的 layered 窗口**（`WS_EX_LAYERED + WS_EX_TRANSPARENT`），任务栏、托盘溢出、工具窗口、弹出菜单都参与识别；候选列表每 500ms 刷新一次，截图过程中新打开的菜单/浮层也能命中。UIA 只返回窗口 / 文档 / 窗格这类粗层时（`UiElementStopReason` 为预算耗尽 / 解码中 / 超时）会继续尝试子窗口或触发一次细化；`ProviderFailure / Cancelled` 则保持窗口级、不重试。

UIA 完全没命中时，再用 **MSAA（IAccessible）** 兜底一次——Electron / 老 Win32 应用经常只在 MSAA 里暴露控件。MSAA 没有超时机制，探测跑在独立线程上；某个应用的 provider 卡住就把它记入黑名单、换新线程继续服务其它窗口，最多放弃 2 个线程后停用，避免线程泄漏。MSAA 命中后会继续沿 `accChild` 往下钻，最多 64 层，直到找到真正包含光标的元素。

设置里可选「窗口元素 API」：

- **自动**（默认）：UIA 优先，MSAA 兜底；
- **仅 UI Automation**：浏览器 / 原生应用；
- **仅 MSAA**：UIA 树异常、但 MSAA 正常的应用。

UIA 侧还有两项和 snow-shot 一致的处理：子节点解码中途预算到点会保留「数组 + 断点」下次续传，不重复付跨进程调用；子节点超过 16 个时建空间索引（均匀网格，等价于它的 R-tree 阈值），避免逐个比较几百个框。

### 3.2 取帧 API（WGC / GDI）

设置里的「截图捕获 API」：

- **自动**（默认）：平时走 GDI（`BitBlt`，最快），检测到 **HDR 显示器**时才用 WGC；
- **Windows Graphics Capture**：强制 WGC，失败仍回退 GDI，保证截图不中断；
- **GDI**：始终 `BitBlt`。

WGC 跨多个显示器时逐屏抓取再拼接；任一屏失败自动回退 GDI。设备只创建一次，每帧用轮询 `TryGetNextFrame`（后台线程没有消息泵，事件模型不会触发）。

### 3.3 截图内容选项

| 选项 | 默认 | 行为 |
|---|---|---|
| 显示光标 | 关 | 普通截图把当前鼠标光标画进图（GDI 用 `DrawIconEx`，WGC 用 `IsCursorCaptureEnabled`）；滚动截图始终不画，避免每帧重复 |
| 滚动截图时捕获界面 | 开 | 开：滚动提示条保留在帧里；关：对它设置 `WDA_EXCLUDEFROMCAPTURE`，从拼接结果里排除 |
| 还原屏幕原始颜色 | 开 | 查询 Windows 放大镜的全屏颜色矩阵并求逆，还原反色/灰度效果（仅 GDI；WGC 返回的本来就是原始像素） |

### 3.4 滚动截图缩略图

滚动截图时，提示条优先放在选区**右侧**（放不下再左侧、底部），显示：

- 已拼接内容的实时缩略图（缩到 280×420 以内，最多 4 帧/秒）；
- `已捕获 N 屏（X px）`；
- 完成 / 取消。

缩略图只采样行列生成，不读整张长图；即使已经转存到临时文件，也最多读 420 行。

拼接完成后在结果窗口右侧还有一条整图缩略条，上下两个琥珀色手柄可以裁掉长图头尾：

- 拖动时实时更新 `宽 × 高 px（原高，上裁 / 下裁）`；
- 「复制 / 保存 / 固定 / 识别」都按裁剪后的行范围导出；
- 不拖就是原图，不做额外解码。

## 四、和 snow-shot 的差异
| snow-shot | Sparrow |
|---|---|
| 工具条可拖动（拖动把手） | 有：拖动把手；选区变动后复位回跟随 |
| 按宽度自动紧凑 | 有：按实测主条宽度把低频动作收进「更多」 |
| 工具分组 + 分隔线 | 有：四个折叠组，支持自定义布局与持久化 |
| 选区尺寸 / 单位切换 / 圆角 / 边框 | 有：X/Y/宽高/比例/圆角，px↔DIP |
| 移动选区保留标注 | 有：按快照反向平移，标注保持屏幕位置 |
| 光标按工具分流 | 有：指针=移动，绘图=十字，文字=I-Beam，边框=拉伸 |
| 选区移动可撤销 | 有：Ctrl+Z / Ctrl+Shift+Z，几何与标注一起回退 |
