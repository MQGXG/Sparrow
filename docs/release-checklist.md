# 发布验收清单（Release Checklist）

> 分三类，**不要混**：
> - **工程验收**：可自动化，每次提交都跑
> - **手工验收**：每次发版前跑
> - **产品验证**：一周后的人工结论，不是发版门槛

---

## 一、工程验收（CI 必须全绿）

### 1.1 构建

```text
[ ] dotnet build 零 warning（TreatWarningsAsErrors 已开）
[ ] dotnet build 零 error
[ ] 所有项目 TargetFramework = net10.0
[ ] global.json 锁定 SDK 10.0.103
```

### 1.2 依赖规则

```text
[ ] Sparrow.Plugin.Sdk 的 ProjectReference 数量 = 0
[ ] Sparrow.Core 只引用 Sparrow.Plugin.Sdk
[ ] plugins/* 只引用 Sparrow.Plugin.Sdk
[ ] plugins/* 的 csproj 不含 Avalonia.*
[ ] Sparrow.Plugin.Sdk 不引用 Avalonia.*
[ ] ViewModel 不引用 Avalonia.Controls.*
```

### 1.3 插件边界（最重要的一组）

```text
[ ] 删掉 plugins/ 下任一插件目录 → 宿主能启动，面板无该工具，无报错
[ ] 插件产物目录里没有 Sparrow.Plugin.Sdk.dll
[ ] 宿主源码不出现具体工具 ID（grep 'sparrow\.(json|ocr|clipboard)\.' 在 Sparrow.App 应为空）
[ ] 每个插件目录名 == plugin.json 的 id
[ ] plugin.json 的 tools 与该插件实际的 Descriptor.Id 一致
[ ] ALC 为 isCollectible: true
[ ] 禁用插件后，ALC 被回收（弱引用已死）
```

检查 SDK 泄漏：

```bash
dir plugins/*/bin/Release/net10.0/Sparrow.Plugin.Sdk.dll
# 必须无输出
```

### 1.4 版本钉死

```text
[ ] SkiaSharp = 3.119.4
[ ] Svg.Skia = 5.1.1
[ ] Avalonia = 12.1.6
[ ] Avalonia.AvaloniaEdit = 12.0.0
[ ] 没有间接引入 SkiaSharp 4.x（dotnet list package --include-transitive 检查）
```

第 5 项最容易漏。检查命令：

```bash
dotnet list package --include-transitive | findstr SkiaSharp
```

出现 `4.x` 就是有人升级了 `Svg.Skia` 或手动加了 SkiaSharp。

### 1.5 测试

```text
[ ] Sdk / Core 单测全绿
[ ] 插件单测全绿（每个插件 ≥ 3 个用例）
[ ] 快照测试全绿
[ ] 无跳过的测试（Skip 必须写原因）
```

### 1.6 性能

| 指标 | 阈值 | 怎么测 |
|---|---|---|
| 冷启动 | < 2.5s | 5 次取中位 |
| 二次唤起 | < 150ms | 按键到可见 |
| 命令搜索 | < 50ms | 13 个工具 |
| 文本工具 | < 100ms | JSON 格式化 1MB |
| 常驻内存（主进程） | < 150MB | 无 OCR 运行 |
| 安装包 | < 60MB | 不含 OCR 组件 |

### 1.7 安全

```text
[ ] 日志中无完整剪贴板内容
[ ] 日志中无密钥
[ ] 日志中无 AI 请求原文
[ ] SVG 输出已过白名单清洗（无 script / on* / foreignObject / 外链）
[ ] 设置的 secrets.bin 权限受限（仅当前用户可读）
```

## 二、手工验收（每次发版）

### 2.1 冷启动与常驻

```text
[ ] 双击图标 → 托盘出现，无窗口弹出
[ ] 右键托盘 → 菜单完整
[ ] 杀进程后重新打开 → 无残留、无重复图标
[ ] 开机自启开启后重启 → 自动进托盘
```

### 2.2 热键

```text
[ ] Ctrl+Alt+S 唤起面板，输入框自动聚焦
[ ] 再按一次 → 面板隐藏
[ ] Esc → 隐藏
[ ] 被其他软件占用 → 有明确提示，且不崩
[ ] 切换显示器后仍能正确唤起（出现在鼠标所在屏）
[ ] 混合 DPI（100% + 150%）下文字不模糊、位置不偏
```

### 2.3 命令面板

```text
[ ] 输入 "json" → 首项是 JSON 格式化
[ ] 输入中文 "格式化" → 能搜到
[ ] ↑↓ 循环选择，不越界
[ ] Enter 执行，结果卡片出现
[ ] 结果耗时显示正确
[ ] 空查询显示最近使用 + 固定项
[ ] 连续搜索 20 次不卡顿
```

### 2.4 三个闭环

```text
闭环 A：剪贴板 -------------------------------------------------
[ ] 复制一段文字 → 500ms 内进历史
[ ] 面板搜到该条 → 回车 → 内容回到剪贴板
[ ] 固定一条 → 重启后仍在
[ ] 搜索历史关键词 → 命中
[ ] 删除一条记录 → 列表和库都消失

闭环 B：JSON ---------------------------------------------------
[ ] 复制 JSON → 面板搜 json → 格式化结果正确
[ ] 切换「压缩」→ 输出无空白
[ ] 输入非法 JSON → 提示行列号，不报堆栈
[ ] 1MB JSON → 100ms 内完成
[ ] 结果可复制，粘贴出来是格式化后的内容

闭环 C：OCR ----------------------------------------------------
[ ] Ctrl+Alt+C → 屏幕变暗，可框选
[ ] 框选文字区域 → 识别结果出现
[ ] 结果可复制
[ ] 识别完 60s 后子进程退出（任务管理器确认）
[ ] 主进程内存回落到 150MB 以内
[ ] 全屏截图（4K）不崩
```

### 2.5 边界

```text
[ ] 复制 500MB 文件到剪贴板 → 程序不卡不崩，历史里标记「过大」
[ ] 复制图片 → 历史里显示缩略图
[ ] 空剪贴板按热键 → 面板正常打开，不报错
[ ] 断网 → 非 AI 工具全部正常
[ ] 磁盘写满 → 有明确错误，不静默失败
[ ] 工具执行中被 Esc 取消 → 无残留进度条
```

### 2.6 插件管理

```text
[ ] 设置页能看到所有插件的列表（名称 / 版本 / 状态）
[ ] 禁用 1 个插件 → 面板里立刻消失，重启后仍禁用
[ ] 启用回来 → 面板里恢复，参数保留
[ ] 删掉一个插件目录 → 重启正常，无报错，其他插件不受影响
[ ] 故意改坏某插件的 plugin.json → 该插件被跳过并提示「清单无效」，其他插件正常
[ ] 故意让插件抛异常 → 面板里灰显「插件异常」，可手动重试
[ ] 连续禁用/启用 10 次 → 任务管理器内存无持续增长
[ ] 把插件目录的 SDK dll 手动放回去 → 日志出现「loaded but no ITool found」（验证铁律 1 的告警有效）
```

最后一项不是找茬，是**验证故障可诊断**——最怕的是插件静默不加载且没有任何提示。

## 四、产品验证（不是发版门槛）

**发版后一周，人工回答一个问题：**

> 你有没有连续 7 天、每天主动唤起 ≥ 3 次，且没有一次觉得「还不如手动」？

| 结果 | 结论 | 下一步 |
|---|---|---|
| 是 | 闭环成立 | 进入下一里程碑 |
| 否，但每天会用 1–2 次 | 方向对，速度不够 | **不加功能**，优化唤起 / 搜索 / 复制路径 |
| 否，几乎不用 | 假设不成立 | 停下来，找真实场景，不要继续堆工具 |

**这一条永远不进 CI。** 它靠人诚实，不靠脚本。

## 五、发版决策表

| 情况 | 是否发版 |
|---|---|
| 工程验收全绿 + 手工验收全绿 | 发 |
| 有 1 项手工验收未过，但非核心闭环 | 发，记 issue |
| 核心闭环（A/B/C 任一）未过 | **不发** |
| 版本钉死被改动 | **不发**，先回滚 |
| 日志/密钥泄露 | **不发**，这是安全事件 |
